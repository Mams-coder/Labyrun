# Assets de Labyrun

Ce dossier est destiné à accueillir les ressources statiques enrichies pour le jeu Labyrun :
- `audio/` : Effets sonores de glissade, sons de victoire, d'accès refusé ou de mode Overdrive.
- `icons/` : Favicons et icônes d'application (PWA).
- `textures/` : Motifs graphiques alternatifs pour les murs et orbes lumineux.
- `fonts/` : Polices personnalisées pour l'affichage rétro-gaming / terminal hacker.
